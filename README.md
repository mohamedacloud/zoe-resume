# Zoe Resume Builder

Zoe Resume Builder is a modern, customizable resume builder built with React and TypeScript.

## 🚀 Features

- Real-time resume preview
- Multiple professional templates
- PDF export support
- Drag and drop sections
- Custom styling options

## 🛠 Tech Stack

- React
- TypeScript
- Tailwind CSS
- Node.js
- PostgreSQL

## 📦 Installation

```bash
git clone https://github.com/navgurukul/zoe-resume-builder.git
cd zoe-resume-builder
pnpm install
pnpm dev
